# 2026-10-27 试查嵌入模型只加载一次

选题：试查页每次提问都重新启动 Qwen3-Embedding-4B，大约 7.5GB 权重被反复加载。

## 做了什么

- `urag try` 在进程启动时打开一个嵌入进程，这个进程结束前一直复用。后面的提问日志写「嵌入模型已在内存」，不再写「加载嵌入模型」。一次提问结束不关掉它。
- 重排模型仍然每次用完就退出。重排前记下嵌入进程；嵌入进程还在时不再启动第二个大模型。
- 空闲内存不够再放一个 4B 时，只在第一次重排前写一次「为重排暂时卸下嵌入」。查询向量继续用常驻嵌入，重排用已有的 0.5 分门槛。
- 3 分钟超时、过程日志和 0 条文案仍在。测试用夹具和假进程，不加载真实 4B。

## 改了哪些路径

- `cmd/urag/try_cmd.go`
- `cmd/urag/mem.go`
- `internal/job/try.go`
- `internal/retrieve`
- `internal/embed`

## 怎么验收

```bash
go test ./internal/web/ -count=1
```

应当通过。不访问外网，不加载真实 4B。

## 未做 / 下一步不要做

- 不要为了试查去停正在跑的收录，也不要新开收录。
- 不要把重排模型和嵌入模型一起留在内存里。
- 不要让每次提问都重新加载嵌入权重。
