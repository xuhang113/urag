# 2026-10-27 试查检索超时

选题：试查页的一次检索会停在「正在检索」。嵌入或重排子进程不返回时，请求也没有结束。

## 做了什么

- `POST /api/try` 最多等 3 分钟。到点结束这次请求，并停掉这次启动的嵌入或重排子进程。
- 页面去掉「正在检索」，显示「检索超时。收录正在占用嵌入模型，这次没有结果。」
- 测试用夹具和会阻塞的假嵌入、假重排，不加载真实 4B。

## 改了哪些路径

- `internal/web`
- `internal/embed`
- `internal/job`
- `docs/operations.md`
- `changelog/2026-10-27-try-search-timeout.md`

## 怎么验收

```bash
go test ./internal/web/ -count=1
```

应当通过。不访问外网，不加载真实 4B。

## 未做 / 下一步不要做

- 不要为了试查去停正在跑的收录，也不要新开收录。
- 不要把重排模型和嵌入模型一起常驻。
