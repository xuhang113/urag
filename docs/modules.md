# 模块

每个 `internal` 包只做一件事。调用方向向下，页面不绕过任务直接碰存储或索引。

| 包 | 负责 | 不负责 | 依赖 |
| --- | --- | --- | --- |
| `model` | 集合、文档、片段、血缘这些共享类型 | 存储、清洗、切分、嵌入、索引、检索、HTTP | 无 |
| `storage` | 按对象键流式存放原文，校验和、幂等、分片、有限次退避 | 解析正文、清洗、建索引；不导出云厂商客户端类型 | `model` |
| `acquire` | 把来源列成条目，并把正文流式交给存储 | 清洗、切分、嵌入 | `model`、`storage` |
| `clean` | 识别类型、转成 UTF-8、去掉样板、在集合内去重 | 切分、嵌入、建索引；不去重其他集合 | `model` |
| `chunk` | 把一篇文档切成带字节区间的片段 | 嵌入、检索；不把不同集合切到一起 | `model` |
| `embed` | 把文本变成向量 | 切分、建索引；密钥不写入日志 | 仅标准库 |
| `index` | 一个集合一个向量索引和关键词索引 | 没有搜索全部集合的方法；不嵌入文本 | `model`、`embed` |
| `retrieve` | 只在点名集合上召回、混合分数、可选重排 | 不打开未点名的集合；不清洗 | `model`、`embed`、`index` |
| `eval` | 夹具类型，以及 Recall@K 和 MRR | 不改写索引；不决定命中顺序 | `model`、`retrieve` |
| `job` | 上传、抓取、清洗、嵌入、检索和评价任务 | 不提供 HTTP 页面；不替换缺失的索引 | 上表除 `web` 以外的包 |
| `web` | 服务端 HTML 和 JSON API | 不算向量；不把上传正文读进内存 | `model`、`job`、`retrieve`、`eval` |

`cmd/urag` 只从环境变量组装上述依赖并调用 `web.Listen`。默认子命令是 `serve`。

## 只有接口的来源

`acquire` 里下面三种来源只有构造函数，调用返回 `ErrNotImplemented`，不是可用实现：

- 数据库：`NewDatabase`
- 站点地图：`NewSitemap`
- 厂商 API：`NewVendorAPI`

本地目录（`NewLocalDir`）和 HTTP（`NewHTTP`）是获取任务会调用的两种来源。数据库、站点地图和厂商 API 不在这次的执行路径里接通。
